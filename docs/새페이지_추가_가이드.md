# 새 페이지 추가 가이드

새로운 서식 페이지를 추가할 때 **반드시 수정해야 할 파일 3개**를 정리합니다.

---

## ✅ 체크리스트

| 순서 | 파일 | 설명 |
|------|------|------|
| 1 | `src/components/app-sidebar.tsx` | **사이드바 메뉴 링크 추가** |
| 2 | `src/App.tsx` | **라우트(Route) 추가** |
| 3 | `src/pages/{통신사}/새페이지.tsx` | **페이지 컴포넌트 생성** |

---

## 1. 사이드바 링크 추가 (`app-sidebar.tsx`)

⚠️ **가장 자주 누락되는 부분!**

```tsx
// src/components/app-sidebar.tsx

const navMain = [
  {
    title: 'KT',
    url: '#',
    icon: Smartphone,
    isActive: location.pathname.startsWith('/kt'),
    items: [
      // ... 기존 항목들
      {
        title: '새 페이지 이름',        // 사이드바에 표시될 이름
        url: '/kt/new-page',           // URL 경로
        isActive: location.pathname === '/kt/new-page',
      },
    ],
  },
  // ...
];
```

---

## 2. 라우트 추가 (`App.tsx`)

```tsx
// src/App.tsx

// 1) import 추가
import NewPage from './pages/kt/NewPage';

// 2) Route 추가
<Route path="kt/new-page" element={<NewPage />} />
```

---

## 3. 페이지 컴포넌트 생성

파일 위치: `src/pages/{통신사}/새페이지.tsx`

예시: `src/pages/kt/KTTheOnePage.tsx`

---

## 📌 참고: menuConfig.ts는 사용되지 않음

`src/constants/menuConfig.ts` 파일이 있지만, 현재 사이드바는 `app-sidebar.tsx`에서 직접 정의한 `navMain` 배열을 사용합니다.

**menuConfig.ts 수정은 효과가 없으므로, 반드시 app-sidebar.tsx를 수정하세요!**

---

## 🔄 템플릿 이미지 추가

새 서식 이미지가 필요한 경우:
1. `src/assets/templates/` 폴더에 이미지 파일 추가
2. 페이지에서 import: `import newImage from '@/assets/templates/새이미지.jpg';`
